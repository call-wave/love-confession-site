# Love Confession Website

เว็บจีบสาวแบบ static เปิดได้ทันทีและ deploy บน GitHub Pages ได้เลย

## เปิดดูในเครื่อง

เปิดไฟล์ `index.html` ใน browser ได้โดยตรง

## Deploy บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. push โค้ดนี้ขึ้น branch `main`
3. ไปที่ Settings > Pages แล้วเลือก Source เป็น GitHub Actions
4. workflow จะ deploy ให้อัตโนมัติ

ลิงก์จะอยู่ในรูปแบบ:

```text
https://<github-username>.github.io/<repository-name>/
```
